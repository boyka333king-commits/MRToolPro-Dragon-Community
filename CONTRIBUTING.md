# Contributing to MRToolPro Dragon Community

Thank you for your interest in contributing extensions and device support to **MRToolPro Dragon**! Please follow these guidelines to ensure smooth integration and maintain project quality.

## Scope of Contributions
This public repository is strictly dedicated to:
- Community extensions and plugins.
- New device support profiles and definitions.
- Bug fixes and compatibility improvements for existing extensions.

## How to Contribute
1. **Fork the Repository:** Create a personal fork of `MRToolPro-Dragon-Community`.
2. **Create a Feature Branch:** Never commit directly to `main`. Create a descriptive branch (e.g., `add-device-support-xyz` or `fix-extension-abc`).
3. **Test Your Changes:** Verify that your extension or device profile works properly without breaking existing functionality.
4. **Submit a Pull Request (PR):** Open a Pull Request targeting the `main` branch with a clear description of what your contribution adds or fixes.

## Code & Security Standards
- Keep code clean, modular, and well-documented.
- Do **not** include hardcoded API keys, credentials, personal tokens, or compiled binary executables (`.exe`, `.dll`, etc.).
- Ensure all submissions comply with the repository's **MIT License**.

## Brand & Intellectual Property
- Official logos, branding assets, and core proprietary software belong exclusively to **MRToolPro Dragon**.
- Do not include unauthorized brand assets or imply official endorsement in third-party extensions without prior permission.
