# MRToolPro-Dragon-Community
Community extensions and device support for MRToolPro Dragon
## Contributing & Phone Vulnerability Research
Community extensions, device support profiles, and safe diagnostic or vulnerability research for **MRToolPro Dragon** are welcome under the **MIT License** and `CONTRIBUTING.md`.

- **Submit a Pull Request:** Use the repository Pull Request template and follow `CONTRIBUTING.md` before requesting a merge into `main`.
- **Report Phone Vulnerabilities or Device Support:** Open an issue using the **Phone Vulnerability & Device Support** template with device model, chipset/platform, OS or security patch details, and safe verification steps.
- **Safety Rules:** Do not submit malicious payloads, unauthorized access tools, precompiled binaries (`.exe`, `.dll`, `.apk`), private keys, or credentials. All submissions require maintainer review.
